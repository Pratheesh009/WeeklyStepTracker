# Weekly Step Tracker – Vector Operations and Analysis

## Overview
This R project demonstrates vector creation and operations, using a weekly step-tracking example.

## Objectives
- Store a sequence of values in a vector.
- Access and analyse individual vector elements.
- Perform basic calculations on vector data.

## Requirements
- R (version 4.0 or later recommended)
- RStudio (optional)

## How to Run
1. Install and open R or RStudio.
2. Open `project3_vectors.R`.
3. Run the script.

## Concepts Covered
- Creating vectors with `c()`
- Indexing and subscripting
- Vector calculations and summaries

## Project Files
- `project3_vectors.R` — main R script

The weekly step-tracker theme is illustrative. Adjust this README to match the values and calculations in your script.
